# Portfolio, Blog và Learning Hub

Hệ thống gồm portfolio phong cách VS Code, blog riêng, lộ trình DSA trực quan và bài giải đa nền tảng. Habit/visionboard là workspace cá nhân; RAG public giúp hỏi nội dung đã công bố.

Stack: React/TypeScript trong frontend-portfolio/, Java 21 + Spring Boot 4.1.1 + Gradle trong backend-portfolio/, PostgreSQL; thêm Redis và Spring AI/pgvector theo từng giai đoạn.
