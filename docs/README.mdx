## Stack đã chốt

| Phần | Lựa chọn |
|---|---|
| Backend và các service tương lai | Java 21, Spring Boot 4.1.1, Gradle Wrapper trong backend-portfolio/ |
| Frontend | React, TypeScript, Vite, React Router, Tailwind và các component hiện có trong frontend-portfolio/ |
| Dữ liệu chính | PostgreSQL, Flyway, Spring Data JPA |
| Bảo mật | Spring Security, admin session cookie và CSRF |
| Cache và rate limit | Redis, bổ sung ở giai đoạn tối ưu |
| RAG | Spring AI, pgvector trong PostgreSQL; Java xử lý cả API và indexing |
| Kiểm tra và vận hành | Spring test support, Testcontainers, Docker, CI |

Thư viện cụ thể và thời điểm thêm nằm trong tài liệu 11. Phiên bản backend lấy từ project hiện có; dependency của các giai đoạn sau phải kiểm tra tương thích trước khi cài.

## Sản phẩm

Portfolio giữ phong cách VS Code. Blog có layout đọc riêng, gồm bài kỹ thuật và hành trình cá nhân. Learning Hub liên kết roadmap → concept → pattern → problem đa nền tảng → solution → visualizer. Habit và visionboard là workspace riêng tư. Backend ban đầu dùng cấu trúc phân lớp đơn giản; vẫn có thể tách service Spring Boot khi nhu cầu thực tế xuất hiện.

Một tác giả/admin; khách đọc không cần tài khoản. Tiến độ khách lưu trên trình duyệt, tiến độ luyện bài của owner lưu server. Bản đầu chưa có tài khoản người học đồng bộ đa thiết bị hoặc hệ thống chấm code.

## Quy trình SDD

SDD là phát triển dựa trên đặc tả: xác định hành vi, dữ liệu, quyền và API trước khi code. Mỗi spec đi qua Draft → Ready → Implementing → Verified. Chỉ ghi Verified khi có bằng chứng kiểm tra.

Lát cắt đầu: admin tạo project nháp → publish → FE đọc được → unpublish → URL public trả 404. Triển khai từ database đến giao diện trước khi mở module tiếp theo.
